Tran Programming Language - Spring 2025

UAlbany Computer Science Project for ICSI311 - Principals of Programming Languages

This was an implementation of a programming language I was assigned to make. I did NOT design the grammar or structure, but instead I 
implemented the Lexer, Parser, and Interpreter Logic.

Lexer - Breaks down string input into a series of tokens (lexemes)
Parser - Reads through token order and makes sure that it's syntactically correct
Interpret = Runs the code 

KNOWN BUGS: Loops don't work properly and possibly conditionals, and it's most likely because booleans are meant to be a built-in object. 
The Iterator method times() doesn't work yet, either.
